# Complete Mathematics Foundation

This section is the full mathematics-first curriculum for coding interviews. Work through the folders in order. Do not add new questions while studying; the complete sequence is already defined here.

## How to use every module

1. Read the concept notes at the top of `exercises.py`.
2. Solve functions from top to bottom.
3. Press the VS Code Run button on `exercises.py`.
4. Two sample tests run first.
5. When samples pass, the complete module test suite runs.
6. Commit completed modules on a weekly practice branch.

## Curriculum

1. Numbers and arithmetic
2. Logic and Boolean reasoning
3. Sets, mappings, and hashing mathematics
4. Functions and relations
5. Counting and combinatorics
6. Complexity and growth
7. Recurrence and recursion mathematics
8. Invariants and correctness
9. Graph mathematics
10. Number theory
11. Probability and bit thinking

Each module contains warm-ups, concept implementations, interview-style problems, edge cases, and challenge problems. Solutions intentionally remain blank so that the repository stays a practice platform rather than an answer sheet.
