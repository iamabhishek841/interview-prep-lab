# Python Practice Track

Use LeetCode for DSA. Use this folder only to build Python fluency from basics to advanced topics.

## Simple workflow

1. Open one numbered `.py` file.
2. Read the tasks from top to bottom.
3. Replace each `pass` or `NotImplementedError` with your own code.
4. Run the file from the VS Code Run button.
5. Compare your output with the expected-output comments.

There is no complex test framework and no nested lesson structure.

## Order

1. Variables, types and operators
2. Conditions and loops
3. Functions and scope
4. Strings
5. Lists, tuples, sets and dictionaries
6. Comprehensions and functional tools
7. Files, exceptions and JSON
8. Object-oriented Python
9. Iterators, generators and decorators
10. Typing, dataclasses, testing and advanced Python

Do not rush. Type every solution yourself. Revisit old files and rewrite solutions without looking.
